## Week 5–6: LSTM Model Development & Evaluation

This folder contains the implementation of an LSTM-based time series forecasting model
for appliance-level energy consumption.

### Week 5
- Designed and implemented LSTM architecture using TensorFlow/Keras
- Prepared sequential time-series data
- Tuned hyperparameters and used EarlyStopping

### Week 6
- Evaluated model using MAE, RMSE, and R² score
- Compared LSTM with baseline Linear Regression
- Saved trained models and scalers
- Implemented and tested prediction function
