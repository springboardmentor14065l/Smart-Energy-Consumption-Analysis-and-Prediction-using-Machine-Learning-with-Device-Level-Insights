# Week 5-6: Energy Consumption Analysis and Prediction

This folder contains the work completed during Weeks 5 and 6 of the internship, focusing on advanced machine learning techniques for energy consumption forecasting.

## Contents

### LSTM Model Implementation
This subdirectory contains the Long Short-Term Memory (LSTM) model implementation for time-series forecasting.
- **LSTM Model Notebook**: Contains data preprocessing, model architecture, training process, and evaluation metrics.
- **Trained Model**: The LSTM model saved in HDF5 format, ready for deployment or further evaluation.
