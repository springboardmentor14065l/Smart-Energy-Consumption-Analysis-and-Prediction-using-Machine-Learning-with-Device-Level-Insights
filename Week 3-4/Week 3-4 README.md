# Week 3–4: Feature Engineering and Baseline Model Development

## Objective

To prepare appliance-level datasets through feature engineering and build baseline machine learning models to predict energy consumption for each appliance.

## Work Done

* Created appliance-wise datasets from the cleaned smart home energy dataset
* Performed **feature engineering** to extract useful variables for modeling
* Split the data into **training and testing datasets** for each appliance
* Organized the processed datasets inside the `appliance_datasets` folder
* Built **Baseline Linear Regression models** for each appliance
* Evaluated model performance using **MAE, RMSE, and R² score**
* Plotted **line graphs** to compare actual vs predicted energy consumption
* Saved the trained models as `.pkl` files for future use

## Notebooks Used

* feature_engineering.ipynb
* baseline_linear_regression_appliance_energy_prediction.ipynb

## Outcome

Appliance-wise datasets were successfully created through feature engineering, and baseline Linear Regression models were trained for each appliance. These models establish an initial benchmark for predicting appliance-level energy consumption and will support further improvements using advanced machine learning techniques.
