## Week 7–8: Model Integration & Dashboard

### Objectives
- Integrate trained LSTM models with a Flask backend
- Develop an interactive web dashboard for energy monitoring
- Provide appliance-wise energy predictions and insights
- Expose prediction functionality through REST API endpoints
- Prepare the system for final demonstration and evaluation

---

### Work Done

- Integrated multiple trained LSTM models into the Flask application
- Dynamically loaded models and scalers for each appliance
- Implemented API endpoints for:
  - Energy prediction
  - Appliance-wise statistics
  - System overview data
- Designed an interactive dashboard using HTML, CSS, and JavaScript
- Visualized predictions, consumption trends, and performance metrics
- Enabled user input to generate real-time prediction results

---

### Week 7–8 Summary

This phase focused on connecting the machine learning layer with the web
application layer. The trained LSTM models were successfully integrated into
a Flask-based backend, enabling real-time inference through API calls.

An interactive dashboard was developed to visualize device-wise energy
consumption, predictions, and analytics. Users can input sample values and
observe predicted energy usage for different appliances.

This integration completed the core system workflow and prepared the project
for final demo, testing, and evaluation.

---

### Technologies Used
- Python
- Flask
- LSTM (TensorFlow / Keras)
- HTML, CSS, JavaScript
- Chart.js (for visualizations)
