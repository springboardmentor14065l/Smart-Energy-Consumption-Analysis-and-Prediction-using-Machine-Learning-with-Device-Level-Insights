# Week 1–2: Data Collection and Preprocessing

## Objective
To understand and prepare smart home energy consumption data for machine learning analysis.

## Work Done
- Collected and explored the SmartHome Energy Monitoring Dataset  
- Analyzed timestamps and device-wise energy usage  
- Performed hourly and daily energy consumption analysis  
- Cleaned the dataset by handling missing values and inconsistencies  
- Resampled data into hourly and daily formats for time-series analysis  

## Notebooks Used
- timestamp_analysis.ipynb  
- hourly_energy_consumption_analysis.ipynb  
- daily_energy_consumption_analysis.ipynb  
- daily_energy_consumption_trend.ipynb  
- data_cleaning.ipynb  

## Outcome
A clean, structured, and time-resampled dataset ready for feature engineering and baseline model development.
