# Week 1-2: Data Exploration and Initial Cleaning

## Overview
This phase focused on understanding the smart home energy consumption dataset and performing initial preprocessing to ensure data quality.

## Key Activities
- **Data Loading**: Imported the original datasets (`smart_home_energy_consumption_large.csv`).
- **Data Cleaning**: Handled missing values, corrected data types, and prepared timestamped versions of the data.
- **Exploratory Data Analysis (EDA)**: Analyzed energy usage patterns across different appliances (Air Conditioning, Fridge, etc.) and environmental factors.
- **Dataset Preparation**: Created cleaned CSV and Excel files ready for feature engineering.

## Files
- `Intial Cleaning and exploration/Smart_Home_Energy_Consumption.ipynb`: Notebook containing the analysis and cleaning logic.
- `Ready For Feature Eng dataset/cleaned_energy_consumption_data.csv`: Output dataset for the next phase.
